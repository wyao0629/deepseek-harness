[English](ARCHIVE.md) | 中文

状态：已封存、半成品、未获验收。按用户要求于 2026-09-16 封存。

## 正确的产品目标

用户需要的是将 PI 子 Agent 扩展移植为 DSH 普通功能插件：模型在正常工作中即可使用协同能力，不需要切换特殊 harness 或 Agent 预设。后续必须先确认本地所指的 pi-sunagent/pi-subagents 扩展，逐项核对真实执行、协同、配置及交互功能，再进行完整移植。

## 本版本被否决的原因

本版本新增了“多 Agent 协作”专用预设，只有该预设获得 Task/TaskWait/TaskList/TaskStop。实际实现仅为四个固定角色的有限任务包装层，并非用户要求的扩展。此前工作受到 Kimi/Codex CLI harness 适配上下文干扰，最初又以 PI-Desktop 内置 Task 实现作为参考。模拟测试和真实任务测试通过，只证明了这些有限机制可运行，不代表满足产品要求。

## 封存处理

源代码、测试及此前技术结论保留在此目录供参考。从服务器当前 DSH profile 移除 bundle、依赖链接及生成的 pi-collab 预设。保留已有会话和无关插件。未经新的明确要求，不继续开发或重新安装此原型。

## 后续验收标准

- 作为普通 DSH 功能使用，不强制选择专用 Agent 预设。
- 对照用户实际指定的 PI 扩展确认功能等价，不根据图表或其他同名近似项目推断。
- 真实任务派发、协同、独立上下文及结果行为与参照扩展对应，可视化配合真实执行。
- 对 DSH 或原生 harness 的能力边界明确说明，不能暗中替换执行架构。

本次封存不包含替代实现。
