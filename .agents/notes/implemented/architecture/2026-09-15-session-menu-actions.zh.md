# Agent Note: 会话菜单扩展

Status: implemented

[English](2026-09-15-session-menu-actions.md) | 中文

## 问题

会话菜单缺少工作目录、直达链接和 Markdown 复制操作；复制过程也需要明确的进度与剪贴板写入结果提示。

## 决策

通过现有 UiWorkspace 服务提供可撤销、可观察的会话菜单描述项。组件通过框架注入的钩子接收描述项，并始终操作被点击的行，不依赖当前活动会话。个人插件 dsh-session-actions 负责复制操作和网址导航。

## 验证

客户端类型检查、工作区打包、85 项相关界面测试和四项插件测试已通过。服务器已在启动清单中声明并提供两份新版客户端文件。真实功能测试会话已导出预期用户与助手文本。浏览器自动化在悬停按钮操作上超时，浏览器交互验收尚未完成。

## 限制

Markdown 包含已落盘的用户与助手正文、代码块和图片占位文字；不包含思考、工具记录和生成中的增量文本。深度链接需要目标页面安装本插件，且不会绕过认证。分页使用打开时的固定日志截点，发生错误时明确报错，不复制部分历史。

## 考虑过的替代方案

在工作区组件中硬编码复制操作会使可选插件与基础菜单耦合；直接注入 DOM 则会绕过菜单生命周期。可撤销的服务注册保留了两者各自的职责。

## 影响

插件依赖个人菜单接口。Markdown 复制通过原生 Toast 显示进度、剪贴板写入后的成功提示和错误信息。嵌套的 remote.session 依赖已明确声明，并由构建入口回归测试覆盖。
