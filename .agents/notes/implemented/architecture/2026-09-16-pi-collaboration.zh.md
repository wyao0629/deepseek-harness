# Agent Note：独立 PI 风格协同

Status: implemented

[English](2026-09-16-pi-collaboration.md) | 中文

## 问题

现有原生 harness 卡片只能展示委派结果，DSH 中缺少独立的 PI 风格多 Agent 协同执行器。

## 决策

新增独立 bundle 和预设 `personal/dsh-pi-collab`。以 PI-Desktop 的任务委派功能为参考，而非仅复制图表。DSH spawn 子会话提供隔离任务上下文、模型路由及现有权限；DSH jobs 负责取消、资源清理和完成唤醒。Task/Wait/List/Stop 包装层提供生命周期控制，不重复实现 LLM 执行循环。

## 考虑过的替代方案

仅接入可视化无法提供任务委派。另建独立 Agent 循环会重复 DSH 的模型和权限处理。复用 spawn 和 jobs，让执行与清理由现有机制负责。

## 影响

子 Agent 共用工作区，不继承主会话历史。异步模型校验前预留并发名额，每个子会话释放后任务才结束。持久化自定义事件将任务元数据和已提交消息关联到独立卡片，不重复发送完整历史快照或逐 Token 日志副本。

任务保存在当前进程，因此重启恢复和自定义角色管理不在此版本范围。Kimi/Codex 原生预设保持原状。工作区中无关的未提交修改已保留。

## 验证

五项聚焦 Node 测试通过。真实双子任务分别返回 ALPHA/BETA；零超时等待保留执行，停止操作取消指定任务，后台完成通知唤醒主 Agent。浏览器检查确认了“功能测试”工作区中的独立思考、输出与真实任务数量。
