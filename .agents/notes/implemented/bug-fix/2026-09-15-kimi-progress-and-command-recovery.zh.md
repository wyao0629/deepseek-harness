# Agent Note: Kimi 进度与命令恢复

Status: implemented

[English](2026-09-15-kimi-progress-and-command-recovery.md) | 中文

## Problem

Kimi 进度投影把缺失的可选字段复制为 undefined。会话持久化拒绝这些数据，但独立托管的原生任务仍继续运行。导入器又排除了所有 DSH 发起的提问，导致最终回答丢失。技能发现还改写了内置命令名称，并丢弃带点号的子命令。

## Decision

进度投影在追加前省略缺失字段。DSH 发起、已失败且尚未保存轨迹的提问仍可恢复；导入器仅写入一次最终回答，不重复用户消息。运行错误携带 KIMI_BRIDGE 错误码。客户端显示中文摘要，并折叠诊断信息。

创建 Agent 时加载原生技能目录。内置技能和带点号的子命令保留原名，外部技能保留限定名和简称。技能通过 DSH 正常消息队列执行，携带原生技能元数据及非空正文。共享命令语法允许点号。

## Alternatives considered

**校验前先序列化。** 这会静默删除缺失字段，掩盖原有回归问题。测试改为要求 JSON 无损往返。

**将提交命令视为执行成功。** 原生完成状态和 DSH 历史响应分别验收，队列接受不代表执行完成。

## Consequences

原生执行可在显示层失败后继续，完成的结果也能回到 DSH。恢复仍保留失败尝试的历史。完整终端命令适配尚未完成：终端选择器、认证及部分会话控制仍需专门适配。
